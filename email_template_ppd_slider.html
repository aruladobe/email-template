Slide 01 — Why tables?
Email template structure — the table-first approach
Why <table> for layout
Outlook uses Microsoft Word's render engine — not a browser. Flexbox and Grid are completely ignored.
Tables have been supported since HTML 3.2 — every client renders them consistently.
Multi-column layouts use nested <td> — reliable in all 20+ major clients.
What to avoid
display:flex — broken in all Outlook desktop versions
display:grid — not supported in Outlook
<div> for layout — Outlook ignores margin & padding on div
Padding on <p> or <div> — use <td> padding only

Slide 05 — Pre-send
Pre-send checklist — before every deployment
Code & structure
  • DOCTYPE html is line 1
  • All layout uses <table> not <div>
  • All critical CSS inlined on every element
  • Images have both width="" attr and style="width:Xpx"
  • All images have descriptive alt text
  • border-collapse:collapse on all tables
  • Total email size under 100KB
Compliance & content
  • Preheader text set — under 90 chars
  • Subject line under 50 characters
  • One-click unsubscribe link present
  • Physical mailing address in footer (CAN-SPAM)
  • Privacy policy & Terms links present
  • Dark mode tested in Apple Mail & iOS
  • Tested in Outlook 2016/2019 + Gmail + Apple Mail
